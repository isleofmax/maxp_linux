# Maxp linux

It's a serie of configuration files created using Grok AI to use Arch Linux with
[labwc]() window manager.
- For the application menu it uses [Fuzzel](https://codeberg.org/dnkl/fuzzel)
- For the bar it uses [waybar](https://github.com/alexays/waybar)
- For the background it use [swaybg](https://github.com/alexays/waybar)

### packages.txt
In this file there the list of packages used to create this version of Arch Linux
